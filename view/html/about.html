📖 关于 Agent

Agent 是一个基于 PyQt5 + QWebEngine 的智能对话系统，集成了 AI 大语言模型、MCP 工具调用、插件扩展等能力。

主要特性：
  • 🧠 多模型支持 - OpenAI、DeepSeek、Claude 等
  • 🔧 MCP 工具系统 - 内置工具 + MCP 协议工具
  • 💬 智能对话 - 流式响应、上下文管理
  • 🔌 插件机制 - 热插拔插件系统
  • 🎨 现代化 UI - 暗色/亮色主题
