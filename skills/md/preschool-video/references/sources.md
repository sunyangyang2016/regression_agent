# 学前教学视频内容源参考

## 内容源优先级（实际可用性）

| 优先级 | 来源 | 可用性 | 说明 |
|--------|------|--------|------|
| 1 | B站（bilibili） | ✅ 稳定 | 资源丰富，yt-dlp `bilisearch` 支持良好，**实际默认源** |
| 2 | 国家智慧教育平台 | ⚠️ 尽力而为 | 内容权威合规，但 `so.smartedu.cn/sousou/searchList` 反爬常返回空，失败自动回退 B站 |
| 3 | 优酷 | ⚠️ 尽力而为 | 部分学前教学资源，搜索页是 JS 渲染 SPA 难稳定抓取，失败自动回退 B站 |
| 4 | 其他公开免费源 | 需确认 | 需确认公开免费 |

> 命令行 `--source` 可选 `自动/bilibili/智慧教育平台/优酷`；目标源抓取失败时脚本自动回退 B站，
> 不会报错或无结果。

---

## 1. 国家智慧教育平台

- **网址**：https://basic.smartedu.cn/
- **搜索入口**：`so.smartedu.cn/sousou/searchList?keyword=<kw>&type=video`（脚本内实现）
- **特点**：权威免费，学前教育板块，内容合规有保障
- **现状**：接口反爬限制，经常返回空列表；脚本会打 ⚠️ 日志并回退 B站，不作为稳定首选。

## 2. B站（bilibili）

- **网址**：https://www.bilibili.com
- **搜索方式**：yt-dlp `bilisearch:` 前缀（脚本内实现）
- **特点**：资源丰富，大量幼教 UP 主，yt-dlp 支持良好
- **搜索建议**：`幼儿园大班 数学 教学视频` / `学前班 拼音 教学`

## 3. 优酷

- **网址**：https://www.youku.com
- **搜索入口**：`so.youku.com/search/q_<kw>` 页面内嵌 `window.__INITIAL_DATA__`（脚本内尽力解析）
- **特点**：部分学前教学资源；页面为 JS 渲染 SPA，curl 只能拿到壳
- **现状**：解析成功与否取决于返回结构，失败自动回退 B站。

## 搜索关键词推荐

### 科目关键词

| 科目 | 关键词建议 |
|------|-----------|
| 数学 | 数学、算术、数字、加减法、认识数字 |
| 语文 | 语文、拼音、识字、汉字、阅读 |
| 英语 | 英语、字母、ABC、natural phonics |
| 科学 | 科学、实验、自然、动植物 |
| 艺术 | 画画、美术、手工、音乐、儿歌 |
| 健康 | 体育、安全、习惯养成、健康 |

### 年级关键词

- 学前班 / 幼小衔接 / 幼儿园
- 大班 / 中班 / 小班

### 组合示例

```
幼儿园 大班 数学 教学视频
学前班 拼音 识字 教学
幼儿园 中班 英语 儿歌
小班 安全 教育 动画
幼小衔接 数学 启蒙
```

## 合规要求

- 仅搜索**公开免费**、有访问权限的视频
- **不绕过** DRM、付费墙或会员权限
- 下载仅用于**个人学习和教学**用途
- 尊重视频作者的版权和平台使用条款
