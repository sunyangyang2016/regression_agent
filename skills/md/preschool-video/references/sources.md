# 学前教学视频内容源参考

## 内容源优先级

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1 | 国家智慧教育平台 | 权威合规，内容官方认证 |
| 2 | B站（bilibili） | 资源丰富，yt-dlp 支持好 |
| 3 | 优酷 | 部分学前教学资源 |
| 4 | 其他公开免费源 | 需确认公开免费 |

---

## 1. 国家智慧教育平台

- **网址**：https://basic.smartedu.cn/
- **特点**：权威免费，学前教育板块，内容合规有保障
- **搜索建议**：使用 site 限定搜索：`site:basic.smartedu.cn 幼儿园 大班 数学`

## 2. B站（bilibili）

- **网址**：https://www.bilibili.com
- **特点**：资源丰富，大量幼教 UP 主，yt-dlp 支持良好
- **搜索建议**：`幼儿园大班 数学 教学视频` / `学前班 拼音 教学`

## 3. 优酷

- **网址**：https://www.youku.com
- **特点**：部分学前教学资源，需要验证链接可用性

## 合规要求

- 仅搜索**公开免费**、有访问权限的视频
- **不绕过** DRM、付费墙或会员权限
- 下载仅用于**个人学习和教学**用途
- 尊重视频作者的版权和平台使用条款
