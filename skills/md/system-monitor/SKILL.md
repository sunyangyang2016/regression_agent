# System Monitor Skill

作为系统监控技能，当用户需要监控系统性能或要求"开始系统监控"时，
**由 AI Agent 严格按本 SKILL.md 的指令执行**以下完整监控流程。

## 职责边界

- **AI 负责**：发现远程 MCP → 采集远程数据 → 智能判断异常 → 写快照 → 推送提醒
- **监控插件只负责**：读取 AI 写入的快照/提醒并纯展示，**绝不接触 MCP、绝不显示本机数据**
- **本 Skill 只提供 AI 指令**，不负责具体的检测实现（检测由远程 MCP 服务器完成）

## 执行流程（AI 每 3 秒循环执行）

用户触发"开始系统监控"后，AI 必须进入 3 秒循环，每轮执行以下动作，直到用户说"停止监控"。

> **轮次纪律**：监控轮次由你（AI）在本轮监控执行期间自行累计——每次"停止监控"
> 结束一轮完整监控后，轮次计数清零；**下一次**再开始监控时从第 1 轮重新计数。
> 严禁引用历史（上一段时间）或记忆中的轮次编号，不得凭空捏造轮数。

### 第 1 步：发现远程 MCP 服务器

通过 MCP 工具调用（tool_call）探测/确认提供系统监控工具的远程服务器（transport 为 http）：
- 优先查找提供以下工具名的远程 MCP 服务器：

| 远程 MCP 工具 | 用途 |
|--------------|------|
| `get_all_stats` | 返回远程设备完整监控数据（CPU/内存/磁盘/网络/进程/汇总） |
| `get_alerts` | 返回远程服务器检测产生的异常提醒列表 |

> 若未找到提供 `get_all_stats` 的远程服务器，向用户报告"未发现远程监控 MCP 服务器，
> 请先配置远程设备监控服务器"。

### 第 2 步：采集远程设备数据

每 3 秒调用远程 MCP 的 `get_all_stats` 工具获取远程设备监控数据。

> **单批次去重约束**：同一次工具调用批次内，每个远程工具（如 `get_all_stats`/`get_alerts`）
> **只能调用 1 次**。若在同一批重复请求相同参数，框架会自动跳过（不执行、只返回"跳过重复调用"），
> 白白占用上下文。「每 3 秒一轮」通过**多轮工具调用**实现——每轮各调 1 次，
> **不要在单批内重复请求相同工具**。

### 第 3 步：智能判断异常

AI **对采集到的远程数据自行分析判断**，识别异常。参考判断维度（不写死阈值，AI 综合判断）：

| 维度 | AI 评估内容 |
|------|------------|
| CPU | 使用率是否持续过高、偶发尖峰 |
| 内存 | 使用率、剩余量、内存泄漏趋势 |
| 磁盘 | 占用率、增长趋势、I/O 异常 |
| 网络 | 带宽、连接数异常激增 |
| 负载 | load 是否持续超过核心数 |
| 进程 | 异常高占用进程 / 可疑进程 |

### 第 4 步：每轮口头汇报

监控面板自动显示 AI 调用远程 MCP 工具返回的结构化数据（CPU/内存/磁盘/进程），**无需写任何快照脚本**。

- 每轮采集分析后，**使用普通文字**向用户简短汇报当前状态（正常/异常摘要）
- 若本轮 AI 判断出明确异常，可输出可选告警标记：
```
{{ALERT: {"level":"warning","title":"CPU 采样尖峰","metric":"cpu","current":"2.15%","threshold":"2%"}}}
```
  `{{ALERT: {JSON} }}` → 插件写入告警队列 → 前端轮询自动显示异常提醒

### 第 5 步：测试完成输出最终总结（显示到面板）

用户说"停止监控"时，**停止采集循环**，然后**输出一次整个测试的最终总结**，用如下标记输出到面板右侧「AI 监控结论」区：

```
{{CONCLUSION: 本次监控共 N 轮，整体健康：CPU 均值 0.5% 空闲，内存 33.4% 稳定，磁盘 52.9% 适中，全程无异常}}
```

- `{{CONCLUSION: ...}}` → 插件写入快照 `ai_judgment` → 面板右侧「AI 监控结论」区显示最终总结
- 总结应包含：总轮次 / 各维度整体结论 / 异常情况汇总
- 这是**整个测试完成后**的唯一一次总结输出

## 监控循环要求

- **严格 3 秒间隔**执行一次远程 MCP 调用，不得跳过周期（多次调用需跨轮进行，勿在单批重复）
- 循环期间持续向用户汇报状态（正常/异常摘要）
- 用户停止后，按第 5 步输出最终总结
- AI 必须保持循环持续运行，直到收到停止指令

## 输出标记说明

| 标记 | 显示位置 | 说明 |
|------|---------|------|
| `{{CONCLUSION: 文本}}` | 面板右侧「AI 监控结论」 | 测试完成后的最终总结 |
| `{{ALERT: {JSON} }}` | 异常提醒面板 | AI 判断的异常（可多条） |

## 可参考文档

- `references/thresholds.md` — 异常判断参考阈值（AI 综合判断，不机械执行）

## 注意事项

- 监控面板**只显示远程数据快照**，绝不显示本机数据
- AI 必须通过远程 MCP 工具调用获取数据，不用本地采集
- 异常判断由 AI 智能完成，参考阈值但不止于阈值
- 远程数据必须写入快照文件供面板读取
