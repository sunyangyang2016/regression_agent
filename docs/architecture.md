# Agent - 系统架构文档

## 概述

Agent 是一个基于 PyQt5 + QWebEngine 的 AI 智能对话系统，集成大语言模型、MCP 工具调用、插件扩展等能力。采用模块化架构设计，各层职责清晰、可独立演进。

## 模块职责

### UI 层 (`ui/`)
- **主窗口**: PyQt5 主窗口管理，系统托盘、快捷键
- **WebView**: QWebEngine 渲染前端 HTML/CSS/JS
- **Bridges**: Python ↔ JS 桥接通信
- **前端资源** (`frontend/`): 独立维护的 CSS/JS/HTML

### 核心层 (`core/`)
- **Agent**: 主控制器，协调各模块
- **Lifecycle**: 生命周期管理（启动→运行→关闭）
- **EventBus**: 事件总线，模块间解耦通信

### AI 层 (`ai/`)
- **Client**: LLM 客户端抽象，统一调用接口
- **Session/Context**: 会话与上下文管理
- **Providers**: 多模型提供商适配（OpenAI、DeepSeek 等）

### 工具/技能/插件
- **Tools** (`tools/`): 工具注册、执行、沙箱
- **Skills** (`skills/`): 技能加载、触发器、执行
- **Plugins** (`plugins/`): 插件加载、钩子系统、依赖解析

### 数据层 (`data/`)
- **Database**: SQLite/PostgreSQL 数据库连接
- **Models**: ORM 模型定义
- **Repositories**: 数据访问层

### API 层 (`api/`)
- RESTful HTTP API + WebSocket 实时通信
- 认证、限流、中间件

## 通信流程

### 用户消息处理

```
用户输入 → WebView → Bridge → Agent.process_message()
    → AI Client.send() → LLM Provider
    → 流式响应 → Agent → Bridge → WebView 渲染
```

### 工具调用

```
Agent → ToolDispatcher → ToolManager.execute()
    → 沙箱执行 → 结果返回 → Agent → AI 处理结果
```
